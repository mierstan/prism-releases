# Prism Browser Releases

Prism Browser 的**公开构建下载仓库**（Windows x64）。源码仓库：<https://github.com/mierstan/prism>。

- 最新版本与校验值见 [Releases](https://github.com/mierstan/prism-releases/releases)；
- 每个版本包含安装版（Setup）与便携版（Portable）两个 exe；
- 下载页：<https://prism.carvel-austin.workers.dev/download/>。

> 本仓库只存放构建产物，不存放源码；构建由 Prism 主仓库 CI/本地 `npm run dist:all` 生成。
